# Welcome to specgit

This document lives in **your repository** — specgit created it on a review branch, so nothing touches your main branch until you publish.

## Try these three things

1. **Edit this line.** Click anywhere and start typing — no Markdown syntax needed. Your changes save automatically as commits.
2. **Leave a comment.** Select some text and add a comment. It becomes a real pull-request review thread on GitHub.
3. **Publish.** Press _Publish_ in the top right when you're ready — specgit merges the pull request and cleans up after itself.

## Why teams use specgit

- Writers get a clean visual editor; reviewers get GitHub pull requests.
- Every edit is a commit and every comment is a PR thread — nothing is stored outside your repo.
- Works with the docs you already have: any Markdown or HTML file.

> Tip: share the link to this doc with a teammate. They can read it instantly and sign in to comment.

Happy writing! When you're done exploring you can delete this file — or keep it as your team's scratchpad.

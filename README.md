# specgit demo

This repository is the live playground for [specgit](https://specgit.com) — a visual editor for the docs already in your GitHub repos. Edits become commits, comments become pull-request review threads, and publishing merges the PR.

Click the badge to open `spec1.md` in specgit — read it instantly, or sign in to comment and suggest edits.

## Add the badge to your own README

```markdown
[![Edit with specgit](https://specgit.com/badge.svg)](https://specgit.com/doc?provider=github&owner=YOUR_OWNER&repo=YOUR_REPO&branch=main&path=docs/YOUR_DOC.md)
```
